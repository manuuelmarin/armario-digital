# Producto y alcance 0.1

El objetivo principal es encontrar prendas repartidas entre ubicaciones y preparar viajes. El flujo habitual debe ser abrir, consultar o modificar y cerrar.

Implementado: inventario con fotos, metadatos opcionales, temporadas múltiples, favoritos, archivo, filtros combinables y búsqueda; ubicaciones editables y traslados masivos; outfits; listas de viaje que importan outfits, deduplican ropa, incluyen otros objetos y muestran la ubicación real; copias y recuperación offline.

El alta exige nombre, categoría y ubicación. La foto es recomendable, pero se permite catalogar una prenda sin ella. Las ubicaciones iniciales son datos editables, no constantes del programa. Las categorías se pueden ampliar desde ajustes.

Los outfits son una biblioteca de ideas. El usuario puede mantener una prenda archivada en una combinación existente; se indica su estado y se impide añadirla a nuevas combinaciones o viajes.

Una maleta es una lista de preparación, no una ubicación. Marcar «preparada» no mueve ropa. La confirmación muestra exclusivamente prendas preparadas que siguen en origen; permite desmarcar las que no se han trasladado. Las de otra ciudad, archivadas o ya en destino no se mueven. Repetir la misma confirmación no duplica movimientos.

Las prendas vinculadas a outfits o viajes no se eliminan definitivamente hasta retirar esas referencias. El archivo permite apartarlas sin perder la información. Eliminar un outfit o viaje no elimina ropa ni revierte traslados físicos.

Fuera de esta entrega: inspiración, meteorología, etiquetas personalizadas, colecciones, duplicación, jerarquías de ubicaciones, múltiples usuarios, sincronización, aplicación móvil, retoque de fondos y recomendaciones automáticas. No se necesita registrar el uso diario.
